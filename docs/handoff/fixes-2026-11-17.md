## 5. Topics on every problem — done

- `src/topics.js` gives each problem up to 5 topics from one fixed list (48):
  staff correction (kept for good) > the judge's tags > words in the title and
  statement > the site's AI model (only when an admin runs it, public statement
  text only). Broad topics (implementation, math, greedy…) rank after telling
  ones (dp, fft…). New problems get theirs after a sync, a statement fetch, a
  staff save, and a minute after start (`TOPICS_STARTUP=0` turns that off).
- Every problem shows a badge for **each** of its topics (owner's ask), drawn
  with the theme's own Badge (`data-ui="badge"`), so all ten themes, light and
  dark, dress them. Problems rows: own line under the title, click filters.
  Solve page: each badge opens Problems filtered to it. Contest picker too.
- Problems: a Topic filter (any number; a problem must have all), in the URL as
  `?topic=dp,graphs`; search understands `topic:dp` and whole topic names.
  The chooser shows real counts. Sources switched off in Admin are not counted.
- Admin → Problem sources → Topics: counts, run/stop the backfill, correct a
  problem's topics by hand (audited), undo a correction.
- Tests: `tests/topics.test.js` (10). Demo: 11,926 Codeforces + CSES problems
  classified, 485 unsure.
