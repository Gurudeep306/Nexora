Identity · round 3

NexoraGuru logo concepts

Four NG monograms, each built from a computer-science idea so the mark tells the product’s story: learn computer science by watching it run. Every mark is live, so hover, move and click to try it. Below each one are its static small sizes and the header lockup on dark and light.

01

Traversal

N and G are one graph. A breadth-first search runs from the first node and splits at the junction, so the letters draw themselves the way an algorithm visits a graph.

  • Hover: send a signal
  • Click: re-run the search
  • Idle: a quiet pulse

Build

The letters are an array of cells pushed in order, column by column, like a stack being filled. Hover sends a ripple through the cells, and an idle scan walks the index.

  • Hover: ripple the cells

03

Caret

The mark types itself in. The cursor waits, types N, moves on, types G, then settles in as the G’s crossbar and keeps blinking. Hover selects the text.

  • Hover: select the text
  • Click: retype
  • Idle: the caret blinks

04

Depth

A glass NG ligature where N’s right stem is G’s spine. It is extruded in real CSS 3D, tilts toward the pointer while the highlight follows it, and spins when clicked.

  • Hover: tilt and catch the light
  • Click: spin
  • Idle: a slow float
