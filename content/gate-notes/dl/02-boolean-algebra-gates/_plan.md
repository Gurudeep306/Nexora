## Lesson 1 · `dl-02-01-logic-gates` · Logic gates and truth tables

**Prerequisites:** dl-01-08 (bits; XOR as "the bits differ").
**Covered by sets:** A 24–29; B 109–113 (incl. positive/negative logic); C 223–229, 254–255; E 407.

### Teaching sequence
1. **Radar** `#radar`; **intuition** `#switches`: a lamp behind switches in series (AND) and in
   parallel (OR); a normally-closed relay (NOT). Animated `switch-model`.
2. **Truth tables** `#truth-table-def`: n inputs → 2ⁿ rows in binary counting order, first variable
   most significant; the row index (used again in Lesson 4).
3. **The three basic gates** `#not-gate`, `#and-gate`, `#or-gate`: symbol, table, expression, the
   "all / any" reading.
4. **Controlling values** `#controlling-value`: 0 forces AND, 1 forces OR; the other value lets the
   input through. The gate as a switch (enable/disable) `#gate-as-switch`.
5. **The derived gates** `#nand-nor` (AND/OR followed by NOT), `#xor-gate` ("differ", odd),
   `#xnor-gate` ("equal"). Animated `gate-symbols` (all seven symbols with their truth tables
   filling row by row).
6. **Tying inputs and constants** `#tie-inputs`: what each gate does with x and x, x and 0, x and 1;
   `:::trick` `#trick-inverter` (every inverting gate becomes a NOT).
7. **All 16 two-input functions** `#sixteen-functions` (a table naming every one; the count
   2^(2²) is derived in Lesson 4).
8. **Multi-input gates** `#multi-input`: AND/OR = all/any; NAND/NOR = complement of all/any; XOR =
   odd parity. `:::trap` `#trap-nand-chain` (a 3-input NAND is not two cascaded 2-input NANDs).
9. **Buffers** `#buffer` (fan-out, delay; tri-state in an aside `#tristate`).
10. **Bubbles and active-low** `#bubbles`; **De Morgan in gate form** `#demorgan-gates` (NAND = OR with
    bubbled inputs, NOR = AND with bubbled inputs), animated `bubble-push`.
11. **Positive and negative logic** `#pos-neg-logic`: one physical gate, two readings; theorem
    `#logic-duality` (changing the convention turns every function into its dual) with proof;
    animated `pos-neg-logic`. `:::trap` `#trap-negative-levels` (−5 V/0 V is still positive logic
    when 0 V means 1).
12. **Reading a circuit** `#read-circuit`: label every gate output, write it, evaluate a row;
    animated `circuit-read`.
13. **Live Lab** `#lab-bench` (Gate Bench, bench tab). GATE question, practice, summary
    `#summary-card`.

### Derivations and proofs
- `:::derivation` the multi-input NAND/NOR as the complement of the multi-input AND/OR, and why the
  2-input NAND chain differs (NAND(NAND(a, b), c) = ab + c′).
- `:::theorem{name="Positive and negative logic are duals"}` + `:::proof`: swapping H ↔ L on every
  wire complements every input and the output, so the function read becomes f(x′)′ = f^D.

### Worked examples (4 per concept)
- **Evaluating gates:** a 3-input AND/OR row (easy); NAND, NOR, XOR on 1011 vs 0110 bitwise (medium);
  tied and constant inputs (GATE); edge case: a 4-input XOR on an input with three 1s.
- **Identify a gate from its table:** outputs 1110 (NAND, easy); 1001 (XNOR, medium); a table in H/L
  read in both conventions (GATE); edge case: a table that is "OR with one input inverted"
  (implication).
- **Bubbles and conventions:** an AND with both inputs bubbled (= NOR, easy); NAND drawn as
  bubbled-OR (medium); negative-logic NOR (= positive NAND, GATE); edge case: mixing conventions
  on input and output (active-low inputs, active-high output).
- **Reading a circuit:** F = (A NAND B) OR C at one row (easy); a three-gate circuit's full table
  (medium); AND–OR–NOT circuit to expression (GATE); edge case: a circuit whose output does not
  depend on one input.

### Tricks and traps
- `:::trick` `#trick-inverter`: NAND(x, x) = NAND(x, 1) = NOR(x, x) = NOR(x, 0) = XOR(x, 1) = XNOR(x, 0)
  = x′. Fails for AND/OR (they give x).
- `:::trick` `#trick-controlling`: scan for a controlling value first (a 0 into an AND, a 1 into an
  OR); it settles the gate without reading the other inputs.
- `:::trap` `#trap-nand-chain`; `:::trap` `#trap-negative-levels`; `:::trap` `#trap-nor-1` (x NOR 1 is 0,
  not x′: the 1999 MCQ).

### Diagrams and animations
- `switch-model` (animate): series and parallel switches with a lamp, toggled through all four rows.
- `gate-symbols` (animate): the seven symbols, inputs A, B stepping 00 → 11, every output and the

- `bubble-push` (animate): AND + output bubble → push the bubble back through the body → OR with

## Lesson 2 · `dl-02-02-boolean-laws` · Boolean algebra: postulates, laws and theorems

**Prerequisites:** dl-02-01. **Covered by sets:** A 33–35; B 104–106; C 189–192, 238–240, 246; D 400.

### Teaching sequence
1. **Radar** `#radar`; intuition `#switch-algebra` (x + x = x, 1 + anything = 1: an algebra of switches,
   not of numbers).
2. **Huntington's postulates** `#huntington` (closure, identities 0 and 1, commutativity, both
   distributive laws, complements, at least two elements). Associativity is a *theorem*.
3. **Duality** `#dual-def` (swap + ↔ ·, 0 ↔ 1; variables and primes stay) and the **duality principle**
   `#duality` (theorem + proof: the postulates come in dual pairs). `:::trap` `#trap-dual-complement`.
4. **The basic theorems** `#laws-table` (identity, null, idempotence, involution, complement,
   commutative, associative, distributive, absorption, De Morgan, consensus, each with its dual),
   with algebraic proofs from the postulates for idempotence `#proof-idempotence`, null `#null-law`,
   absorption `#absorption`, the redundant-literal rule `#redundant-literal` (x + x′y = x + y), the
   uniqueness of the complement `#unique-complement` and involution.
5. **Perfect induction** `#perfect-induction`: a truth table *is* a proof (finitely many cases);
   animated `law-cards` (2-row and 4-row proofs).
6. **De Morgan's laws** `#demorgan` (theorem + proof through the uniqueness of the complement); the
   general rule `#demorgan-general` (complement = dual with every literal complemented); animated
   `complement-tree`.
7. **Consensus** `#consensus` (xy + x′z + yz = xy + x′z, proof by splitting yz on x) and its dual
   `#consensus-dual`; using it backwards to *add* a term `#consensus-add`; animated `consensus-cells`.
8. **Simplification strategy** `#simplify-method`: expand/flatten, absorb, redundant literal,
   consensus, factor; stop when no rule shrinks the expression.
9. **Shannon expansion** `#shannon` (theorem + proof), cofactors `#cofactor-def`, the POS form
   `#shannon-pos`; animated `shannon-tree`.
10. **Proving and disproving identities** `#prove-disprove`: algebra or perfect induction to prove,
    one counterexample to disprove; the 0/1 test `#counterexample` (trick with when-it-fails).
11. **Boolean equations** `#bool-equations`: a sum is 0 ⇔ every term is 0; a product is 1 ⇔ every
    factor is 1; f = g ⇔ f ⊕ g = 0 `#equation-to-zero`; systems by sieving rows; animated
    `equation-sieve`.
12. **What is not a law** `#not-laws`: no cancellation (x + y = x + z ⇏ y = z), no subtraction or
    division. `:::trap` `#trap-cancel`.

### Derivations and proofs
- Algebraic proofs from the postulates: idempotence, null law, absorption, x + x′y = x + y,
  uniqueness of the complement, involution, De Morgan, consensus (both forms), Shannon expansion,
  associativity (sketched, deep).
- `:::theorem` duality principle + proof; `:::theorem` De Morgan + proof; `:::theorem` consensus +
  proof; `:::theorem` Shannon + proof; `:::derivation` f = g ⇔ fg′ + f′g = 0.

### Worked examples (4 per concept)
- **Laws and absorption:** x + xy (easy); x′y′ + xy + x′y (medium, the 2004 MCQ pattern);
  (P + Q′)(PQ′ + PR)(PR′ + Q′) (GATE); edge case: x + x′y + x′y′ = 1.
- **De Morgan and complements:** (AB + C)′ (easy); complement of (A + B′C)(A′ + D) (medium); the
  complement of a POS read as SOP (GATE, the 2021 pattern); edge case: dual vs complement of x′ + y′.
- **Consensus:** AB + A′C + BC (easy); (A + B)(A′ + C)(B + C) (medium); add a consensus term to factor
  xy′ + yz′ with one complement (GATE, the 2002 pattern); edge case: a term that looks like a
  consensus but is not (AB + A′C + BC′).
- **Shannon:** expand f = AB + A′C on A (easy); on B (medium); which expansion is false (GATE, the
  2006 pattern); edge case: f(0, …) + f(1, …) is the *existential* quantifier, not f.
- **Equations:** AB + A′C = 1 with AC + B = 0 (easy); a four-variable system (medium); a system with
  two solutions (GATE); edge case: x + y = x + z does not give y = z.

### Tricks and traps
- `:::trick` `#trick-absorb-scan`: before expanding, look for a term that contains another (absorb it)
  and for a literal whose complement stands alone (drop it). Fails inside XOR or under a bar.
- `:::trick` `#counterexample`: for "which is NOT valid", test the all-0, all-1 and one-hot rows first.
  Fails to *prove* validity (only disproves).
- `:::trap` `#trap-dual-complement`; `:::trap` `#trap-cancel`; `:::trap` `#trap-consensus-fake`;
  `:::trap` `#trap-shannon-literals` (dropping the literals in the expansion).

## Lesson 3 · `dl-02-03-xor-and-operators` · XOR/XNOR algebra and custom operators

**Prerequisites:** dl-02-02. **Covered by sets:** A 24–29; B 109–112; C 227–229, 247–248, 255–256.

### Teaching sequence
1. **Radar** `#radar`; intuition `#xor-intuition` (the "differ" lamp, addition without carry, a
   controlled inverter); animated `xor-controlled-inverter`.
2. **Forms of XOR and XNOR** `#xor-forms`, `#xnor-forms` (SOP, POS, (x + y)(xy)′).
3. **XOR laws** `#xor-laws` (x ⊕ 0, x ⊕ 1, x ⊕ x, x ⊕ x′, commutative), associativity `#xor-assoc`
   (theorem + proof through parity), cancellation `#xor-cancel`, solving `#xor-solve`
   (a ⊕ b = c ⇔ a = b ⊕ c), AND distributes over XOR `#and-over-xor` (OR does not, `#trap-or-xor`).
4. **Complemented inputs** `#complement-inputs`: x′ ⊕ y = x ⊕ y′ = (x ⊕ y)′, x′ ⊕ y′ = x ⊕ y.
5. **XOR as addition mod 2** `#gf2` (x ⊕ y = x + y − 2xy), OR in XOR form `#anf`
   (x + y = x ⊕ y ⊕ xy) and the disjoint case `#disjoint-or` (xy = 0 ⇒ x + y = x ⊕ y).
6. **Parity** `#parity` (theorem: an n-input XOR is 1 iff an odd number of inputs are 1, proof by
   induction); animated `xor-parity-chain`; iterated XOR `#iterated-xor`; `:::trap` `#trap-n-times`.
7. **XNOR as equivalence** `#xnor-equivalence`; chains of XNOR `#xnor-chain` (an odd number of
   variables gives the same function as XOR; an even number the complement; "1 iff the number of 0s
   is even"); `:::trap` `#trap-xnor-convention` (an n-input XNOR gate vs a chain).
8. **Operator properties** `#operator-properties` (commutative, associative, idempotent, identity,
   absorbing element) and how to test them from a table `#test-from-table` (symmetry; the 8-row
   associativity test, animated `assoc-test`).
9. **NAND and NOR are not associative** `#nand-not-assoc` (theorem + counterexample).
10. **Implication-type operators** `#implication` (x → y = x′ + y; not commutative, not associative).
11. **Defined operators** `#defined-operators` (method: identify which of the 16 functions it is,
    then use its laws) and **nested operators** `#nested` (evaluate inside out).

### Derivations and proofs
- `:::theorem` XOR is associative + proof (both bracketings are 1 exactly on odd-weight rows).
- `:::theorem` parity of an n-input XOR + proof by induction.
- `:::derivation` x ⊕ y = x + y − 2xy and x + y = x ⊕ y ⊕ xy; `:::derivation` complementing inputs.
- `:::theorem` NAND is commutative but not associative + proof by counterexample.
- `:::derivation` the XNOR chain: x₁ ⊙ … ⊙ xₙ = x₁ ⊕ … ⊕ xₙ ⊕ (n − 1 mod 2).

### Worked examples (4 per concept)
- **XOR algebra:** 1 ⊕ x ⊕ x′ (easy); flatten and cancel ((1 ⊕ P) ⊕ (P ⊕ Q)) ⊕ ((P ⊕ Q) ⊕ (Q ⊕ 0))
  (GATE, the 2014 pattern); (x + y) ⊕ xy (medium); edge case: (x + y) ⊕ z vs x ⊕ (y + z).
- **Parity:** parity of 1011 0110 (easy); which minterms an odd-parity function has (medium); the
  2016 "x₁ ⊕ x₂ ⊕ x₃ ⊕ x₄ = 0, what must hold" (GATE); edge case: B XORed n times.
- **Operator properties:** test a table for commutativity (easy); associativity of NAND (medium);
  associativity of a ≠-table (GATE); edge case: an operator that is associative but not commutative
  (x * y = x).
- **Defined and nested operators:** x * y = x′ + y, z * x (easy); A * B = AB + A′B′ with C * A
  (medium); x # y from four properties (GATE); edge case: f(f(x + y, y), z).

### Tricks and traps
- `:::trick` `#trick-flatten`: for any XOR chain, count each variable's copies mod 2 and count the 1s
  mod 2. Fails as soon as an AND/OR sits between two XORs.
- `:::trick` `#trick-bubble-count`: in XOR/XNOR expressions, count the complements (on inputs and on
  the output): an even total leaves XOR, an odd total gives XNOR.
- `:::trap` `#trap-or-xor`, `#trap-n-times`, `#trap-xnor-convention`, `#trap-nand-assoc` (NAND(NAND(a,b),c)
  is not a 3-input NAND).

## Lesson 4 · `dl-02-04-canonical-forms` · Minterms, maxterms and canonical forms

**Prerequisites:** dl-02-02. **Covered by sets:** A 36–37, 43; B 105–108, 112–113; C 192–198,
241–244, 253–254, 268–269; E 408.

### Teaching sequence
1. **Radar** `#radar`; intuition `#row-detectors` (build f as an OR of detectors, one per 1-row).
2. **Terms** `#terms-def` (literal, product, sum), **SOP and POS** `#sop-pos`.
3. **Minterms** `#minterm-def` (index = the row number, first variable MSB) and **maxterms**
   `#maxterm-def`; `#minterm-maxterm-complement` (Mᵢ = mᵢ′).
4. **Canonical SOP** `#canonical-sop` and **POS** `#canonical-pos`; uniqueness `#canonical-unique`
   (theorem + proof); animated `minterm-highlighter`.
5. **Σ ↔ Π** `#sigma-pi`; `:::trap` `#trap-sigma-pi` (f = Σ(S) ⇒ f′ = Π(S), not Σ(S)).
6. **Expanding terms** `#expand-terms` (multiply in (v + v′)); term size `#term-size` (a k-literal term
   of n variables covers 2ⁿ⁻ᵏ minterms); `:::trick` `#trick-dash` (write the term as a pattern like
   1 1 − and read the minterms).
7. **Minterm-set algebra** `#minterm-sets` (AND = ∩, OR = ∪, NOT = complement, XOR = symmetric
   difference; theorem + proof); animated `minterm-set-venn`; Live Lab `#lab-sets` (sets tab).
8. **Counting functions** `#count-functions` (2^(2ⁿ)), with exactly k minterms `#count-k-minterms`

## Lesson 5 · `dl-02-05-universal-gates` · Universal gates and functional completeness

**Prerequisites:** dl-02-04. **Covered by sets:** A 29–32, 43; B 111–112, 117–118; C 229–232,
250–252, 279; D 400.

### Teaching sequence
1. **Radar** `#radar`; intuition `#one-brick`.
2. **Functional completeness** `#complete-def`; {AND, OR, NOT} is complete `#aon-complete` (theorem
   via canonical SOP); {AND, NOT} and {OR, NOT} `#two-op-complete` (De Morgan supplies the third).
3. **NAND is universal** `#nand-universal` (NOT 1 gate, AND 2, OR 3); **NOR** `#nor-universal` (NOT 1,
   OR 2, AND 3); animated `nand-builds`. Properties `#nand-properties` (commutative, not associative,
   not idempotent).
4. **XOR and XNOR from NAND/NOR** `#xor-4-nand` (4 NAND; derivation), the count table
   `#gate-count-table` (XOR 4 NAND / 5 NOR, XNOR 5 NAND / 4 NOR); minimality `#xor-min-proof` (why 3
   gates cannot, plus our exhaustive search); animated `xor-from-nand`.
5. **Two-level forms** `#nand-nand` (SOP → NAND–NAND) and `#nor-nor` (POS → NOR–NOR); bubble pushing
   as the conversion `#bubble-conversion`; animated `nand-nand-conversion`; `:::trap`
   `#trap-single-literal` (a lone literal needs an inverter in the second level).
6. **Minimum gate counts** `#min-count-method` (best form, count, then a lower-bound argument);
   AB + C with NOR = 3 gates.
7. **Is a set complete?** `#completeness-test` (build NOT and AND or OR); constants `#constants` and
   partially complete sets `#partial-complete`.
8. **Post's five classes** `#post-classes` (0-preserving, 1-preserving, self-dual, monotone,
   affine); theorem `#post-theorem` with the necessity proof (each class is closed under wiring);
   with free constants only monotone and affine matter `#with-constants`; animated
   `completeness-checklist`.
9. **Complete with constants** `#complete-with-constants`: the 2:1 MUX `#mux-complete`,
   {AND, XOR, 1} `#and-xor-1`, implication with 0 `#imp-complete`, half adders `#half-adder-complete`;
   not complete: {XOR, NOT}, {AND, OR}, majority.
10. **A single complete function** `#single-function-test` (Sheffer functions; only NAND and NOR among
    the 16 two-input functions) `#sheffer`.
11. **Live Lab** `#lab-challenge` (NAND-only / NOR-only challenge).

### Derivations and proofs
- `:::theorem` {AND, OR, NOT} complete + proof; `:::derivation` NAND/NOR builds and counts.
- `:::derivation` XOR = NAND(NAND(A, G), NAND(B, G)) with G = NAND(A, B).
- `:::theorem` Post's criterion + proof of necessity (closure of each class), sufficiency sketched
  (deep).
- `:::theorem` exactly two 2-input Sheffer functions + proof (from the five classes).

### Worked examples (4 per concept)
- **NAND/NOR builds:** NOT and AND from NAND (easy); OR from NOR (medium); A + B′ + C with one inverter
  and one NAND (GATE, the 1995 pattern); edge case: a 3-input NAND from 2-input NANDs (3 gates,
  with an inverter).
- **Two-level and multi-level conversion:** AB + CD to NAND–NAND (easy); (A + B)(C + D) to NOR–NOR
  (medium); the 2002 AND–OR–OR circuit in six 2-input NANDs (GATE); edge case: AB + C needs an
  inverter on C in NAND–NAND.
- **Minimum counts:** XOR with NAND (easy, 4); AB + C with NOR (medium, 3); XNOR with NAND (GATE, 5);
  edge case: A′B costs 2 NORs but 3 NANDs (computed by search).
- **Completeness:** {XOR, NOT} (easy, no: affine); 2:1 MUX with constants (medium, yes); implication
  (GATE, needs 0); edge case: f = X′YZ + XY′ + Y′Z′ alone (the 2015 pattern).

### Tricks and traps
- `:::trick` `#trick-post-quick`: check the corners first: f(0…0) = 0 or f(1…1) = 1 rules out
  "Sheffer" at once; a function written without primes is monotone. Fails when constants are free.
- `:::trap` `#trap-single-literal`; `#trap-naive-count` (converting gate by gate gives 5 for AB + C
  with NOR); `#trap-constants` (whether 0/1 are allowed changes the answer).

## Lesson 6 · `dl-02-06-gate-circuit-analysis` · Analysing gate circuits and timing

**Prerequisites:** dl-02-04, dl-02-05. **Covered by sets:** A 24; B 108–109; C 199–202, 223–226,
245–246.

### Teaching sequence
1. **Radar** `#radar`; intuition `#follow-the-signal`.
2. **The analysis method** `#analysis-method` (label every wire, write each gate, substitute,
   simplify; or tabulate rows); animated `signal-flow`.
3. **NAND/NOR circuits** `#nand-nor-circuits` (a NAND fed by NANDs is an OR of ANDs; a NOR fed by
   NORs is an AND of ORs); XOR circuits `#xor-circuits`; redundant inputs `#redundancy`.
4. **Circuits of function blocks** `#block-equations` (f = f₁f₂ + f₃ as set algebra); solving for an
   unknown block `#solve-block` (theorem: h must contain f − g and lie inside f; it is unique only
   for XOR) and `#xor-block` (h = f ⊕ g); animated `block-sets`.
5. **Wrong-gate puzzles** `#wrong-gate` (AND replaced by NAND: NAND(NAND(a, b), c) = ab + c′).
6. **Switch networks** `#switch-networks` (series = AND, parallel = OR, paths of a bridge) and the
   **staircase switch** `#staircase` (XNOR/XOR); animated `staircase-switch`.
7. **Propagation delay** `#prop-delay`, critical path `#critical-path`.
8. **Timing diagrams** `#timing-method` (events, intervals, evaluate each).
9. **Glitches** `#glitch` (X·X′ with a slow inverter gives a 1-pulse on the rising edge; X + X′ a
   0-pulse on the falling edge); pulse generators and edge detectors `#xor-edge-detector`
   (A ⊕ A delayed by δ gives a δ-wide pulse at every edge); animated `glitch-timing` and
   `xor-delay-timing`. Aside `#ring-oscillator` (odd inverter loop, f = 1/(2N·t_pd)).
10. **Live Lab** `#lab-bench` (bench tab, for checking any circuit by its truth table).

### Derivations and proofs
- `:::theorem` solving f = g + h for h + proof; `:::derivation` XOR blocks are invertible.
- `:::derivation` NAND–NAND = AND–OR, NOR–NOR = OR–AND (De Morgan).
- `:::derivation` the X·X′ glitch width equals the inverter delay; the XOR-delay pulse width equals δ.

### Worked examples (4 per concept)
- **Reading circuits:** a NOT–AND–OR circuit to minterms (easy, the 2020 pattern); four NORs (medium,
  the 1993 pattern); seven NORs where P drops out (GATE, the 2010 pattern); edge case: an input that
  cancels (the 2005 pattern).
- **Blocks:** f = f₁f₂ + f₃, find f₃ (easy); find f₂ (medium); XOR block (GATE, the 2019 pattern);
  edge case: no solution exists (g not inside f).
- **Wrong gates and switches:** one AND→NAND (easy); a four-term expression (GATE, the 2007
  pattern); staircase switches (medium); edge case: a bridge network with an X and X′ path.
- **Timing:** path delay of a 3-level circuit (easy); X·X′ glitch (medium); A ⊕ A(t − 2) ⊕ … (GATE,
  the 2003 pattern); edge case: X + X′ and the 0-glitch on the falling edge.

### Tricks and traps
- `:::trick` `#trick-nand-pairs`: in a NAND–NAND circuit, erase bubble pairs on each wire; what is left
  is AND–OR. Fails when a wire has an odd number of bubbles (a NAND used as an inverter in between).
- `:::trick` `#trick-set-first`: with Σ lists, never write expressions; do set operations on the index
  lists.
- `:::trap` `#trap-glitch-edge` (the 1-glitch of X·X′ is on the *rising* edge only),
  `#trap-steady-state` (a circuit can be logically 0 and still glitch).

## Chapter Live Lab: Gate Bench (`:::lab{lab="gate-bench"}`)

A new reader block (`:::lab`, leaf, attributes `lab` and `tab`), rendered by a lazily loaded
component in `client/src/gate/notes/labs/`. Logic lives in a pure, dependency-free module
`gateBench.ts`, tested in `tests/gate-notes.test.js` against vectors that
`_checks/dl/l2_lab_vectors.py` writes and verifies with `boollib`.

1. **Bench** (lessons 1 and 6): inputs A, B, C (2 or 3 of them) as toggles; add AND, OR, NOT, NAND,
   NOR, XOR, XNOR or BUF gates; wire each gate input from a menu of earlier signals; pick the output.
   The circuit is drawn by levels with live wire values; the truth table fills in with the current
   row highlighted, and the Σ and Π lists are shown. Presets: XOR from four NANDs, the majority
   function, a half adder's sum.
2. **NAND-only / NOR-only challenge** (lesson 5): pick a target (NOT, AND, OR, XOR, XNOR, AB + C, the
   majority) and a family; only that gate is offered; "Check" compares the truth tables and reports
   the gate count against the proven minimum.
3. **Minterm sets** (lessons 4 and 6): enter f and g as Σ lists over 3 or 4 variables and see f·g
   (∩), f + g (∪), f ⊕ g (Δ) and f′ as Σ and Π lists and as a cell strip.
