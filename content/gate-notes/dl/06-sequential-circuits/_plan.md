## Lesson 1 · `dl-06-01-latches` · Feedback, latches and races

**Prerequisites:** dl-02-06 (gate analysis and delay). **Covered by sets:** A 76–78; B 134–135;
C 326–333; E 406.

### Teaching sequence
1. **Radar** `#radar`; intuition `#memory-intuition` (a light switch that stays where you leave it
   versus a doorbell: memory is a circuit that remembers which button was pressed last).
2. **Feedback creates memory** `#feedback-def` (a loop from an output back to an input; the
   circuit's output now depends on its own past); `:::definition` `#stable-state` (a stable state is
   an assignment of the loop wires that reproduces itself: $Q = f(x, Q)$); theorem
   `#stable-theorem` (a single-loop circuit with loop function $f(x, Q)$ is: a constant for input x
   when exactly one of $f(x, 0) = 0$, $f(x, 1) = 1$ holds; a memory (two stable states) when both
   hold, i.e. $f = Q$; an oscillator (no stable state) when neither holds, i.e. $f = \bar Q$) + proof;
   method `#feedback-analysis` (cut the loop, tabulate $f(x, Q)$ for Q = 0 and 1, read the stable
   values); animated `feedback-stability`; `:::trap` `#trap-odd-ring` (an odd number of inversions
   round a loop with no other input can never be stable: the ring oscillator).
3. **The SR latch** `#sr-nor` (cross-coupled NORs; S sets, R resets, 00 holds); characteristic
   table `#sr-table`; `:::derivation` `#sr-equation` ($Q^+ = S + \bar R Q$ with $SR = 0$);
   animated `sr-latch-feedback` (set, hold, reset, hold, both 1, both released → oscillation);
   forbidden input `#forbidden` (S = R = 1 forces Q = Q̄ = 0, breaking the complement rule);
   theorem `#race-theorem` (from S = R = 1, releasing both inputs at once with equal gate delays makes
   the latch oscillate; with unequal delays the faster gate decides, so the final state is
   unpredictable) + proof; `:::trap` `#trap-forbidden` (the trouble is the release, not the 11 itself).
4. **The NAND latch** `#nand-latch` (active-low $\bar S$, $\bar R$; 11 holds, 00 is forbidden and
   gives Q = Q̄ = 1); animated `nand-latch`; `:::trap` `#trap-nand-00` (2004: the answer is "Q = Q̄ =
   1", not "indeterminate"; IT 2007: 00 → 11 is the oscillating sequence); comparison table
   `#nor-vs-nand`.
5. **Gated latches** `#gated-latch` (an enable C gates S and R; transparent while C = 1);
   `#d-latch` (S = D, R = D̄ removes the forbidden input); theorem `#d-latch-theorem` ($Q^+ = CD +
   \bar C Q$) + proof; MUX latch `#mux-latch` (a 2:1 MUX whose output feeds the data input it
   selects when S = 0 is a D latch; 2023); animated `mux-latch`; `:::trap` `#trap-dff-vs-latch`
   (2023 offers "D flip-flop": the MUX circuit is level-sensitive, so it is a latch).
6. **Latch versus flip-flop** `#latch-vs-ff` (transparent while enabled vs samples at an edge;
   erratum X6 / C 332 in a `:::note`); why transparency is a problem in a loop `#transparency-problem`
   (a counter built from latches races; motivates Lesson 2).
7. **Live Lab** `#lab-latch` (Flip-flop Scope, scope tab: an SR or D latch driven by hand).
   GATE questions, practice, summary `#summary-card`.

### Derivations and proofs
- `:::theorem` single-loop stability (constant / memory / oscillator) + proof; `:::derivation` SR
  equation; `:::theorem` the release race + proof (equal delays: the symmetric state 00 maps to 11
  and back; unequal: the first gate to switch wins); `:::theorem` D latch equation + proof.

### Worked examples (4 per concept)
- **Feedback analysis:** a single OR with its output fed back (easy: once 1, stuck at 1); the 1991
  majority loop $Q = aQ + ab + bQ$ (medium); the 1999 AND chain (GATE); edge case: a NOR with
  feedback (1993), which oscillates unless a + b = 1.
- **SR and NAND latches:** trace a NOR latch through 10, 00, 01, 00 (easy); a NAND latch through
  01, 11, 10, 11 (medium); the 2004 NAND 00 question (GATE); edge case: IT 2007, which input
  sequence oscillates.
- **Gated and D latches:** a D latch with a given C and D waveform (easy); the gated SR latch with S
  = R = 1 while C = 1 (medium); the 2023 MUX circuit (GATE); edge case: a D latch whose D changes
  while C = 1 (the output follows: transparency).

### Tricks and traps
- `:::trick` `#trick-cut-loop` (cut the loop, compare f(x, 0) and f(x, 1)); `#trick-active-low`
  (NAND latch: think "0 does the work").
- `:::trap` `#trap-odd-ring`, `#trap-forbidden`, `#trap-nand-00`, `#trap-dff-vs-latch`.

## Lesson 2 · `dl-06-02-flip-flops` · Flip-flops: SR, JK, D, T, edge triggering and timing

**Prerequisites:** dl-06-01. **Covered by sets:** A 79–86, 99; B 135–138; C 333–342; D 400; E 406–407.

### Teaching sequence
1. **Radar** `#radar`; intuition `#edge-intuition` (a camera shutter: the photo is whatever is in
   front of the lens at the click, not what happens before or after).
2. **Edge triggering** `#edge-def` (positive / negative edge; the clock symbol; the output changes
   only after an active edge); animated `edge-ff-timing` (D latch vs positive-edge D flip-flop on the
   same waveforms); `:::trap` `#trap-level-vs-edge` (reading a flip-flop as a latch).
3. **Master–slave** `#master-slave` (two gated latches on opposite clock phases); theorem
   `#ms-theorem` (a master–slave D flip-flop with ideal latches samples D at the falling edge and its
   output changes only then) + proof; animated `master-slave`; pulse-triggered JK and 1s-catching
   `#ones-catching` (deep).
4. **The four flip-flops** `#ff-types`: SR, JK (toggle on 11), D, T; characteristic tables and
   equations `#char-equations` ($Q^+ = S + \bar R Q$, $J\bar Q + \bar K Q$, $D$, $T \oplus Q$) with a
   `:::derivation` each from its table; `:::trap` `#trap-t-next` (erratum B 183: Q⁺ = T ⊕ Q, not T).
5. **Race-around** `#race-around` (a level-triggered JK with J = K = 1 toggles every t_pd while the
   clock is high); theorem `#race-around-theorem` (during a clock pulse of width t_w a level JK latch with
   J = K = 1 starts a toggle every t_pd while the clock is still high, so it toggles ⌈t_w / t_pd⌉
   times; it toggles exactly once iff t_w ≤ t_pd; erratum X5) + proof; animated `race-around`; cures (master–slave, edge triggering).
6. **Excitation tables** `#excitation` (the inputs needed for each transition Q → Q⁺; don't-cares)
   with a `:::derivation`; `#ff-design-from-diagram` (realise a given state diagram with a JK: IT 2008).
7. **Converting flip-flops** `#conversion` (excitation table of the available flip-flop, K-map of
   each input over the wanted inputs and Q); `:::derivation` `#jk-from-d` ($D = J\bar Q + \bar K Q$),
   `#t-from-d`, `#d-from-jk`, `#jk-from-t` ($T = J\bar Q + KQ$); animated `ff-conversion`.
8. **Asynchronous preset and clear** `#preset-clear` (override the clock; active-low on most
   symbols; erratum C 345: preset forces 1).
9. **Timing parameters** `#timing-params` (setup t_su, hold t_h, clock-to-Q t_cq); theorem
   `#setup-hold-window` (an input change inside (t_e − t_su, t_e + t_h) can leave the flip-flop
   metastable; outside it, the sampled value is the value just before the edge) + proof sketch;
   animated `setup-hold`; maximum clock frequency `#max-frequency` (T ≥ t_cq + t_logic + t_su; hold
   check t_cq + t_logic,min ≥ t_h) with a `:::derivation`; `:::trap` `#trap-edge-change` (an input
   that changes exactly at the edge with t_h = 0 is read as its old value; 2001).
10. **Reading timing diagrams** `#timing-diagram-method` (mark the active edges, read each input just
    before the edge, update, repeat; 2001, 2005); phase shifting with edges `#phase-delay` (2006: a
    positive-edge then negative-edge pair delays by one period, 180° of the fastest f).
11. **Live Lab** `#lab-scope` (Flip-flop Scope, scope tab) and `#lab-tables` (tables tab).

### Derivations and proofs
- `:::theorem` master–slave sampling + proof; `:::derivation` each characteristic equation;
  `:::theorem` race-around count + proof; `:::derivation` excitation tables from the characteristic
  equations; `:::derivation` four conversions; `:::theorem` setup/hold window + proof sketch;
  `:::derivation` the timing inequalities.

### Worked examples (4 per concept)
- **Characteristic equations and tables:** next state of each type for a given row (easy); JK
  sequence for J, K waveforms (medium); the 2000 master–slave pair (GATE); edge case: a T flip-flop
  driven by T = Q̄ (Q⁺ = Q̄ ⊕ Q = 1: it sets once and stays at 1, a trap).
- **Excitation and conversion:** JK excitation table (easy); D from JK (medium); IT 2008 J and K
  for a two-state diagram (GATE); edge case: SR from JK (the forbidden row becomes a don't-care).
- **Timing:** a D flip-flop waveform with t_cq (easy); f_max from t_cq, t_logic, t_su (medium);
  the 2001 X/Y diagram (GATE); edge case: a hold violation from a short path.
- **Timing diagrams and phase:** 2005's Y sequence (medium); the 2006 phase question (GATE); a
  negative-edge flip-flop on the same input (easy); edge case: an input pulse that falls between
  two edges is never seen.

### Tricks and traps
- `:::trick` `#trick-before-edge` (read the input just left of the edge); `#trick-excitation` (JK
  excitation = "the bit you need, then x").
- `:::trap` `#trap-level-vs-edge`, `#trap-t-next`, `#trap-edge-change`, `#trap-same-edge` (two
  flip-flops on one edge both see old values: the second does not see the first's new output).

## Lesson 3 · `dl-06-03-sequential-analysis` · Analysing synchronous sequential circuits

**Prerequisites:** dl-06-02. **Covered by sets:** A 76–77; B 154–155, 183; C 326–328. Analysis of
given circuits is thin everywhere (GAP: written from Mano and Ciletti, ch. 5).

### Teaching sequence
1. **Radar** `#radar`; intuition `#analysis-intuition` (a board game: the position now and the dice
   decide the next position; the circuit's rules are its wires).
2. **Synchronous vs asynchronous** `#sync-vs-async` (one clock for every flip-flop; why it wins:
   hazards and races settle between edges); theorem `#sync-discipline` (if the clock period exceeds
   the longest path, every flip-flop samples a settled value, so glitches cannot cause errors) +
   proof; `:::trap` `#trap-sync-faster` (1991: "faster" and "less hardware" are not the advantage).
3. **The analysis procedure** `#analysis-procedure` (1 name the state bits and their order, 2 write
   each flip-flop's input equations, 3 substitute into the characteristic equations to get the state
   equations, 4 tabulate next state and output for every state and input, 5 draw the state diagram);
   `#excitation-equations`; `#state-equations`; animated `circuit-to-state-table`.
4. **State tables and diagrams** `#state-table` (present state, input, next state, output; one row
   per state × input); `#state-diagram` (circles, arcs labelled input/output); reading a diagram back
   into equations `#diagram-to-equation` (IT 2006).
5. **Tracing** `#clock-trace` (from an initial state, clock by clock; all flip-flops update together
   from the old values); `:::trap` `#trap-update-order` (updating one flip-flop and using its new value

## Lesson 8 · `dl-06-08-state-minimisation` · State minimisation

**Prerequisites:** dl-06-07. **Covered by sets:** E 409 only (GAP: written from Kohavi and Jha, and
Mano and Ciletti). DFA minimisation proofs (Myhill–Nerode) belong to Theory of Computation.

### Teaching sequence
1. **Radar** `#radar`; intuition `#equiv-intuition` (two shop assistants who give the same answer to
   every possible sequence of questions are interchangeable).
2. **Equivalent states** `#equivalent-states` (same output for every input sequence); theorem
   `#equivalence-relation` (state equivalence is an equivalence relation and merging a class keeps the
   behaviour) + proof; k-equivalence `#k-equivalence`.
3. **Partition refinement** `#partition-refinement` (P₀ by outputs, P_{k+1} by the blocks of the next
   states, stop when nothing splits); theorem `#refinement-correct` (P_k is exactly k-equivalence and
   the process stops within n − 1 rounds with the equivalence classes) + proof; animated
   `partition-refinement`; `:::trap` `#trap-moore-p0` (Moore: P₀ by the state's output; Mealy: by the
   whole output row).
4. **The implication table** `#implication-table` (pairs; cross out on output mismatch, then on implied
   crossed pairs, repeat); theorem `#implication-agrees` (the uncrossed pairs are exactly the
   equivalent pairs) + proof; animated `implication-table`.
5. **Unreachable states** `#unreachable` (drop them first; they cost flip-flops but never matter).
6. **Counting states from words** `#min-states-from-words` (2003: what must the machine remember?);
   lower bounds `#distinguishing-strings` (n pairwise distinguishable strings ⇒ ≥ n states).
7. **Incompletely specified machines** `#incomplete` (brief: compatibility is not transitive, so
   classes may overlap; deep).
8. **Why minimise** `#why-minimise` (flip-flop count ⌈log₂ k⌉ and logic; when merging does not save a
   flip-flop).
9. **Live Lab** `#lab-minimise` (Counter & FSM Simulator, fsm tab: Minimise).

### Worked examples (4 per concept)
- **Partition refinement:** a 4-state Mealy table (easy, 1996); a 6-state Moore table (medium); the
  2025 8-state table (GATE); edge case: a machine already minimal (P₀ = P₁ = P_final).
- **Implication tables:** the 1996 table (easy); the 2025 table (GATE); a machine with a two-pass
  crossing (medium); edge case: a pair that implies itself (it stays uncrossed: equivalent).
- **States from words:** a parity checker (easy); "difference of 0s and 1s reaches 2" (GATE, 2003);
  a mod-3 remainder machine (medium); edge case: a detector where a naïve design has an extra
  equivalent state.

### Tricks and traps
- `:::trick` `#trick-output-rows` (group by output rows first, it usually does most of the work);
  `#trick-distinguish` (to prove two states differ, show one input string).
- `:::trap` `#trap-moore-p0`, `#trap-unreachable`, `#trap-same-next` (equal next states are not
  required; next states in the same block are enough).
