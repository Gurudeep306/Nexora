# GATE notes inventory (internal)

Reference material only. Sets are labelled A, B, C… in file order; author names, institutes
and watermarks are deliberately not recorded. Nothing from these files is published: lessons
are written in Nexora's own words with our own diagrams (see the build prompt, §1.2).

**13 files · 6,574 pages.** Each file is one subject with several independent note
sets marked by bookmarks. Pages 1–3 of every file are a cover, a list of sets and a topic finder.

**Not covered by any notes:** General Aptitude, and the DA-only subjects (to be written from the
official syllabus, standard textbooks and our PYQ bank).

## Scan quality key

| Rating | Meaning |
|---|---|
| good | Clear handwriting, one page per scan; render at 200 dpi. |
| spreads | Phone-scanned two-page spreads, small writing, curved pages; render at 250 dpi and read each half. |
| dense | Dense two-up pages on ruled paper, faint; render at 250-300 dpi. |
| faint | Readable but faded or with bleed-through; render at 250 dpi. |
| noisy | Speckled scan; readable at 250 dpi. |
| typed | Typed or digital short notes and solved questions; text layer partly usable. |
| reference | Typed formula handbook or textbook pages: use only to check facts, never as a teaching model. |
