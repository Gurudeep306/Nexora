# Nexus courses

One Markdown file per concept: `content/courses/<subject>/<concept>.md`, and an optional
`content/courses/<subject>/index.md` for the subject page. The ids are the ones in
`content/nexus/<subject>.json`. A concept without a file shows "Course coming soon".

See `content/nexus/README.md` → Courses for what the pages show and the Markdown supported.
